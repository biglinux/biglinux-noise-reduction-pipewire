# Community code of conduct

BigLinux Microphone welcomes contributors and users with different backgrounds and levels of experience.

Be respectful, specific and technical when discussing problems. Critique code and behavior rather than people. Do not harass, threaten, discriminate against, or publish private information about another participant.

Maintainers may edit, hide or remove contributions that are abusive, spam, disclose private/security-sensitive data, or repeatedly disrupt technical collaboration. Serious security reports should follow [SECURITY.md](SECURITY.md) rather than being posted publicly.

When a disagreement is technical, prefer reproducible evidence: code, tests, measurements, documentation and clearly stated assumptions.
