# Archived design/review notes

Files in this directory are historical investigation or implementation plans. They are retained only when they still explain a decision or measurement that may be useful during maintenance.

They are **not** the current runtime contract. Current behavior is documented in `README.md`, `AGENTS.md` and the maintained documents one directory above.

Large one-off patch bundles, copied source snapshots and validation evidence should live in release/review artifacts rather than the main source tree.
