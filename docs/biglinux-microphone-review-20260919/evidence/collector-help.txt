usage: collect_hardware.py [-h] --out OUT [--seconds SECONDS]
                           [--interval INTERVAL] [--pid PID]

Observe-only Linux/PipeWire diagnostics. DOES NOT record audio or set volume.
Creates a NEW private directory. May expose device/user/application names in
logs. No install, service restart, profile change or persistent settings
modification. Snapshots before/after perturb scheduling; exclude those edges
from A/B results.

options:
  -h, --help           show this help message and exit
  --out OUT            new directory; existing path is refused
  --seconds SECONDS
  --interval INTERVAL
  --pid PID            extra PID, e.g. GUI; repeatable
